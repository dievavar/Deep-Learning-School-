
# Deep Learning School (DLS) Repository

Этот репозиторий содержит материалы и практические задания, выполненные в рамках обучения первого семестра в **Deep Learning School (DLS)** Школы глубокого обучения ФПМИ МФТИ, который посвящён основам нейросетей, свёрточным нейронным сетям и компьютерному зрению. . 
Здесь представлены работы по ключевым темам современного машинного и глубокого обучения, от базовых концепций до более сложных архитектур нейронных сетей.


## 📁 Структура репозитория

Каждая папка соответствует отдельному семинару (домашнему заданию) и содержит код (ноутбуки Jupyter `.ipynb`).

---

## 🧠 Подробное описание семинаров

### **Семинар 1: Введение в машинное обучение и библиотеку Scikit-Learn**
*   **Ключевые темы:** Основы ML, подготовка данных, линейная регрессия, логистическая регрессия, метрики качества (MSE, Accuracy, Precision, Recall, F1-score), кросс-валидация.
*   **Задачи и реализация:** Знакомство с pipeline в `sklearn`, решение задач регрессии (предсказание цен) и классификации (например, Iris dataset). Построение первых моделей, их оценка и настройка гиперпараметров.
*   **Цель:** Получить фундаментальное понимание workflow машинного обучения, не используя нейронные сети.

### **Семинар 2: Введение в нейронные сети с PyTorch/TensorFlow**
*   **Ключевые темы:** Основы фреймворков для глубокого обучения (PyTorch или TensorFlow/Keras), класс `Dataset` и `DataLoader`, устройство полносвязной сети (Multilayer Perceptron - MLP), функции активации (ReLU, Sigmoid), функция потерь и оптимизаторы (SGD, Adam).
*   **Задачи и реализация:** Реализация собственного класса для работы с данными, построение архитектуры нейронной сети с помощью `nn.Module` или `keras.Sequential`, обучение модели на стандартных наборах данных (например, MNIST или Fashion-MNIST).
*   **Цель:** Научиться использовать основной инструментарий для создания и обучения нейронных сетей.

### **Семинар 3: Сверточные нейронные сети (CNN) для классификации изображений**
*   **Ключевые темы:** Архитектура CNN, сверточные слои, пулинговые слои (MaxPooling), выравнивание (Flatten), dropout для борьбы с переобучением, transfer learning.
*   **Задачи и реализация:** Построение собственных сверточных сетей (например, `Conv2D -> ReLU -> MaxPool2D -> ...`) для задач компьютерного зрения. Использование предобученных моделей (VGG, ResNet, EfficientNet) из `torchvision.models` или `tensorflow.keras.applications` для ускорения обучения и повышения точности.
*   **Цель:** Понять принципы работы CNN и научиться применять их к реальным задачам классификации изображений.

### **Семинар 4: Регрессия и детекция объектов**
*   **Ключевые темы:** Задача регрессии в компьютерном зрении (предсказание координат, а не классов), задача детекции объектов, IoU (Intersection over Union), основы архитектур детекции (например, R-CNN, YOLO — возможно, на уровне использования или простой реализации).
*   **Задачи и реализация:** Обучение модели для предсказания bounding box'ов (ограничивающих прямоугольников) на изображении. Это могла быть либо кастомная CNN, предсказывающая 4 числа, либо fine-tuning существующей модели детекции.
*   **Цель:** Выйти за рамки классификации и решить более сложную задачу локализации объектов.

### **Семинар 5: Генеративные состязательные сети (GAN)**
*   **Ключевые темы:** Принцип работы GAN: генератор vs. дискриминатор, adversarial loss, обучение с подкреплением в контексте GAN.
*   **Задачи и реализация:** Реализация простой GAN (например, Deep Convolutional GAN - DCGAN) для генерации изображений (часто на датасете MNIST или Faces). Обучение двух противоборствующих сетей в одном тренировочном цикле.
*   **Цель:** Понять концепцию генеративных моделей и получить практический опыт создания сетей, способных генерировать новые данные.

### **Семинар 6: Обработка естественного языка (NLP) с RNN и LSTM**
*   **Ключевые темы:** Векторизация текста (Bag of Words, TF-IDF, Word Embeddings), рекуррентные нейронные сети (RNN), ячейки с долгой краткосрочной памятью (LSTM) для учета контекста, работа с последовательностями.
*   **Задачи и реализация:** Классификация текстов (например, анализ тональности отзывов) с использованием embedding-слоев и архитектур RNN/LSTM. Работа с библиотеками `nltk`/`spacy` для предобработки текста.
*   **Цель:** Научиться применять глубокое обучение к текстовым данным, понимать особенности работы с последовательностями.

### **Семинар 7: Трансформеры и BERT**
*   **Ключевые темы:** Архитектура Transformer (механизм внимания — Attention, Self-Attention), предобученные языковые модели (BERT, GPT), fine-tuning для downstream-задач (классификация, NER, QA).
*   **Задачи и реализация:** Использование библиотек `transformers` (Hugging Face) для загрузки предобученных моделей (например, `bert-base-uncased`) и их адаптации под конкретную задачу (например, классификацию текста).
*   **Цель:** Освоить state-of-the-art подходы в NLP, основанные на архитектуре Transformer.

### **Семинар 8: Автокодировщики (Autoencoders)**
*   **Ключевые темы:** Принцип работы автокодировщиков (encoder-bottleneck-decoder), обучение без учителя, поиск аномалий, понижение размерности, вариационные автокодировщики (VAE).
*   **Задачи и реализация:** Построение автокодировщика для задачи шумоподавления на изображениях или для поиска выбросов в данных. Изучение латентного пространства.
*   **Цель:** Понять применение нейронных сетей для задач обучения без учителя и сжатия данных с сохранением ключевых особенностей.
